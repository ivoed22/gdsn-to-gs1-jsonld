# v0.32.0 — Product Journey Bridge + Report Center

## Overview

Third version of the end-product build path. Two changes that turn the
five workflows into one story:

1. A converted product can continue straight into the Product Passport
   builder — no more download-then-re-upload.
2. Every conversion produces a self-contained, printable HTML report —
   the shareable artifact a stakeholder conversation ends on.

## Product Journey bridge

- Convert's Export step gains a **"Continue to Product Passport"**
  button (`continue_to_product_passport` in `app/workflow_shared.py`,
  same on-click-callback pattern as the v0.26.0 Explorer deep link). It
  stores the generated JSON-LD and GTIN in session state and switches to
  the Product Passport workflow.
- The passport builder's Input tab detects the bridged payload and
  offers it as a pre-selected input mode — "Converted in this session
  (GTIN …)" — alongside the unchanged upload/paste/example paths.
- **Honesty guarantee:** the bridged payload goes through the exact same
  `normalize_gs1_jsonld_input` parsing/validation as an uploaded file.
  This is transport convenience, not a validation bypass.

## Report Center

- New pure module `src/gdsn_to_gs1_jsonld/report.py`:
  `build_product_report_html(jsonld_data=..., validation_report=...,
  mapping_report_rows=..., unmapped_fields=..., codelist_validation=...)`.
- One HTML document per product: identity (GTIN, name, `@id`), the
  v0.31.0 readiness assessment rendered verbatim (level badge, all four
  dimensions including the honest `not_yet_assessed_pending_crosswalk`
  DPP-relevance status, scope note), mapping evidence summary, codelist
  validation counts, and the generated JSON-LD in a `<pre>` block.
- **Fully self-contained:** inline CSS only (DESIGN.md color tokens
  inlined as literals), no `<script>`, no `<link>`, no external
  stylesheet/image/font references — test-enforced. Opens identically
  from an email attachment, fully offline, and print-previews cleanly.
- **Deterministic:** same conversion in, same bytes out (no timestamp
  unless a caller passes `generated_note` explicitly).
- **No-claims-safe:** every restricted claim phrase appears only
  negated; the governance footer renders "Not official GS1 validation.
  No production compliance claim. Not an EU DPP conformity assessment."
  verbatim — test-enforced with the same phrase/negator check as
  `tests/test_no_claims.py`.
- Convert offers it as a 5th download ("Download product report
  (HTML)"); the export package caption reads "5 files".

## Also in this version

- Visual smoke: the Mapping Governance candidate-generation drive picks
  the property via keyboard (type + Enter) instead of clicking inside
  the BaseWeb virtual dropdown, which kept timing out on CI runners
  (non-blocking failures in the v0.30.0/v0.31.0 runs).

## Verification

- 5 new unit tests (`tests/test_report.py`): identity/readiness/evidence
  content, self-containment (HTML-parser sweep for external `src`/`href`
  and forbidden tags), negation of every restricted claim phrase,
  determinism + bytes round-trip, and the not-evaluated codelist path.
- 1 new AppTest (`test_product_report_download_and_journey_bridge`)
  driving convert → report download present → Continue → builder shows
  the pre-selected bridged input parsed through the normal path.
- Download-count AppTests updated from 4 to 5 (deliberate invariant
  change).
- Full suite: 315 passed.

## Preserved

- No converter/serializer/validator changes.
- No warnings suppressed; no official GS1 validation or production
  compliance claimed — including in the outward-facing report.
