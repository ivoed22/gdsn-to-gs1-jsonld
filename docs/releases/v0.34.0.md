# v0.34.0 — GS1 Digital Link Preview + QR

## Overview

Fifth version of the end-product build path, promoted from the roadmap's
"Later" list. A converted product's demo now ends on a tangible artifact:
the GS1 Digital Link URI form for its GTIN and a scannable QR code —
both constructed fully offline, with the limits stated plainly.

## What changed

- **New pure module `src/gdsn_to_gs1_jsonld/digital_link.py`.**
  - `build_digital_link_uri(gtin)` → `https://id.gs1.org/01/{gtin}`,
    the same URI form the converter's `jsonld_builder` already emits as
    `@id`. Digits-only input validation; full GTIN check-digit
    validation remains the converter/validator's job.
  - `digital_link_qr_svg(uri)` → QR code as an SVG string, rendered
    locally with `qrcode`'s `SvgPathImage` factory (pure paths, no
    raster imaging dependency). Deterministic: same URI, same SVG.
- **Honesty constraint, test-enforced.** The shared
  `DIGITAL_LINK_CAVEAT` wording appears wherever the URI is shown:
  "GS1 Digital Link URI form constructed offline from the GTIN. This
  does not check or claim that the link is registered, resolvable, or
  live." No code in the module performs any network call.
- **Convert (Single XML) step 3** renders a "GS1 Digital Link" panel
  after the readiness scorecard: URI code block + QR + caveat. The
  panel is skipped entirely for an unusable GTIN.
- **The HTML product report** (v0.32.0) embeds the same section — the
  SVG inlines, so the report remains fully self-contained and
  deterministic.
- **Dependency:** `qrcode` added to `pyproject.toml` main dependencies
  (the library module imports it; CI's `pip install -e ".[dev]"` picks
  it up) and to `requirements.txt` for Streamlit Cloud — which also
  lost seven accidental duplicate lines while being touched.

## Verification

- 4 new unit tests (`tests/test_digital_link.py`): URI form parity with
  the converter's `@id`, rejection of unusable GTINs, QR SVG
  well-formedness/determinism/self-containment, and the caveat wording
  explicitly negating registered/resolvable/live.
- Report tests extended: URI + inline SVG + caveat present; the
  existing self-containment parser sweep still passes with the
  embedded SVG.
- AppTest extended: the panel shows the example GTIN's URI and caveat
  after conversion.
- Full suite: 320 passed.

## Preserved

- No converter/serializer/validator changes; `@id` generation is
  untouched (the new module mirrors its form, used for presentation
  only).
- Fully offline; no warnings suppressed; no official GS1 validation or
  production compliance claimed.
