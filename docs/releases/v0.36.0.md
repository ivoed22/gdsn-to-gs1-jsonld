# v0.36.0 — Consolidated mapping review and result layout

This release combines the Antigravity, Gemini, ChatGPT Deep Research and
ChatGPT decision files into an auditable consensus layer for the 288 published
GDSN-to-WebVoc suggestions scoring at least 60%.

Consensus never changes executable JSON-LD. It identifies unanimous and strong
agreement, ordinary acceptance consensus, unresolved human-review cases and
conflicts. The complete reviewer votes and recommended next action remain in
the unmapped evidence download.

The Cloudflare PWA now presents results in the requested visual order:
downloads, JSON-LD output, checks, mapping suggestions and supporting detail.
The unfinished Product Passport continuation has been removed from conversion
results, and the unmapped-source path column has been widened.
