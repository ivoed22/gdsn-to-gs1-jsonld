# v0.38.1 — Clean fully embedded review output

The fully embedded review variant now removes each review-only
`schema:additionalProperty` node after its value has been placed under the
proposed GS1 or Schema.org property. This avoids duplicate values and removes
the contradictory statement that an already embedded value is not asserted.

The default review-safe variant is unchanged and continues to retain the full
review evidence without asserting candidate mappings. Unrelated legitimate
`schema:additionalProperty` nodes are preserved in both variants.
