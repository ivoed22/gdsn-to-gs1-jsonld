# v0.37.0 — Structured supplier output and removable review evidence

The online converter now defaults to structured review profile v0.5. It emits
reviewed Web Vocabulary structures for supplier/contact data, target market,
country of origin, packaging, gross weight, functional and regulated product
names, and referenced product-image metadata.

Unresolved 60%+ candidates remain visible in the JSON-LD as removable
`schema:PropertyValue` evidence. The candidate property is recorded as a
literal `schema:propertyID` and is not asserted as a GS1 predicate. This avoids
turning similarities such as `contactName → gs1:contactType` into false facts.

The UI also displays the percentage share belonging to every AI consensus
category alongside the per-candidate similarity percentage and vote count.
