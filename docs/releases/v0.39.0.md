# v0.39.0 — Clean product and separate mapping review

The converter now produces a clean product JSON-LD document as its default
output. AI confidence, consensus and candidate mappings are available in a
separate mapping-review JSON file and are not product facts.

The experimental fully embedded review variant remains available for human
assessment, but is not presented as publishable product data.

Mapping profile v0.6 adds standards-backed structural improvements:

- allergen and containment codes are explicit GS1 code-node references;
- target-market countries are typed `gs1:Country` objects;
- contact data is grouped in a typed `gs1:ContactPoint`, with a contact name
  represented using `schema:name`;
- product images include `gs1:referencedFileType` as a GS1 code-node reference.

`gs1:packagingType` and `gs1:countryCode` remain strings because their official
Web Vocabulary ranges are `xsd:string`. Values without a source language remain
tagged `und`; the converter does not infer Dutch merely from the text.
